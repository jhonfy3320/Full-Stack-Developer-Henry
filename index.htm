Bienvenido a mi sitio web

Este es un proyecto creado para practicar HTML semántico, estructura web, organización de contenido y buenas prácticas.

Temas vistos en el Módulo 1

En esta sección se presentan los temas principales trabajados durante el módulo, acompañados de una imagen, nombre y breve descripción.

Introducción al Desarrollo Web y HTML Semántico

Aprendimos la estructura básica de una página web usando etiquetas semánticas como header, nav, main, section, article, aside y footer para organizar mejor el contenido.

CSS Fundamentos y Diseño Visual

Trabajamos con estilos visuales para mejorar la presentación de una página web, aplicando colores, tipografías, espaciados, cajas, layouts y diseño responsive.

Git, GitHub y Control de Versiones

Practicamos el uso de Git para controlar cambios en el código y GitHub para guardar proyectos en la nube, colaborar y mantener un historial ordenado.

JavaScript Fundamentos y Lógica de Programación

Estudiamos los fundamentos de JavaScript, variables, tipos de datos, condicionales, ciclos, funciones y lógica necesaria para dar comportamiento a las páginas web.

Manipulación del DOM, Eventos y DevTools

Aprendimos a seleccionar elementos HTML desde JavaScript, modificar contenido, responder a eventos del usuario y usar las herramientas del navegador para depurar errores.

AI Prompting para Desarrollo Web

Utilizamos inteligencia artificial como apoyo para generar ideas, mejorar código, resolver errores, documentar proyectos y acelerar el proceso de desarrollo web.

Deployment con GitHub Pages

Aprendimos a publicar una página web para que deje de estar solo en local y pueda ser visitada desde internet mediante GitHub Pages.

Proyecto Integrador 1

Integramos los conocimientos adquiridos en HTML, CSS, JavaScript, DOM, Git, GitHub, IA y despliegue web para construir un proyecto completo.

Sobre mí

Soy un estudiante de desarrollo web full stack en formación, practicando HTML, CSS, JavaScript, DOM, Git, GitHub y publicación web.
